# PHA Health Management & Governance Platform

Platform for Provincial Health Authorities in Papua New Guinea covering HR, facilities, projects, governance, BPM workflows, and offline-first rural connectivity. It integrates with existing systems (IFMS, Alesco, Facilities Establishments, Clinical HIMS, SMS Gateway) rather than replacing them.
